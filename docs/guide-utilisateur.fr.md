# Guide utilisateur (squelette) — SmartCommerce AI

## 1. Premiers pas

1. Créer un compte marchand (`/fr/register`).
2. Une organisation + boutique démo sont créées (essai).
3. Publier des produits → vitrine `/fr/s/{slug}`.

## 2. Ventes

- Catalogue, panier, checkout (carte / Mobile Money sandbox / COD).
- Dashboard **Commandes** / **Paiements**.
- Les paiements ne passent `paid` qu’après confirmation provider/webhook.

## 3. WhatsApp & Social

- **Inbox WA** : conversations, handoff humain.
- Consentement marketing requis pour relances panier / campagnes.
- **Social** : connecter Meta/TikTok (OAuth) ; publication et Ads avec confirmations explicites.

## 4. Studio Pubs AI

- Packs copy (sales / acquisition / brand), visuels, scripts vidéo.
- Crédits AI selon le **plan SaaS**.
- Sans clé OpenAI : échec explicite (pas de faux succès).

## 5. CRM & Stats

- **CRM** : profils, segments, fidélité, coupons, réclamations, campagnes consenties.
- **Stats** : CA, AOV, conversion, attribution WA/Meta/TikTok, ROI pubs, stock, paniers.
- Assistant analytique : conseils ancrés sur KPI réels.

## 6. Abonnement

- Plans **Starter $19 / Business $49 / Premium $99** (frais plateforme).
- Distinct des coûts externes Ads, WhatsApp, AI, frais de transaction.
- Sans billing provider : impossible d’activer un plan payant « en silence ».

## 7. Sécurité

- Activer **MFA** (TOTP) pour les comptes sensibles.
- Export / anonymisation des données personnelles.
- Super-admin plateforme : orgs, stores, abonnements, intégrations.
